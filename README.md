# CLEANER - Инструменты для работы с ИИ-текстами

Комплексный набор Python-инструментов для работы с текстами, сгенерированными искусственным интеллектом.

## 🚀 Основные возможности

### 1. Очистка текста от Unicode-артефактов
Удаление невидимых символов Unicode, которые добавляет ИИ при генерации текста.

### 2. Детектор ИИ-текста (AI Detector)
Определение искусственности текста с оценкой 0-100% на основе эвристических методов:
- Анализ однородности предложений
- Поиск характерных фраз ИИ
- Оценка лексического разнообразия
- Частота переходных слов
- **Работает локально, без подключения к интернету!**

### 3. Анализ паттернов (Pattern Analyzer)
Поиск повторяющихся конструкций и шаблонов, характерных для ИИ:
- Повторяющиеся n-граммы
- Шаблонные выражения
- Чрезмерно используемая лексика
- Однородность структуры предложений

### 4. Водяные знаки и стеганография (Watermarking)
Защита авторских прав с помощью невидимых водяных знаков:
- Встраивание метаданных в текст
- Два типа: концентрированный и распределенный
- Проверка подлинности
- Сохранение информации об авторе

## Описание

Этот набор инструментов автоматически работает с текстовыми документами (.txt и .docx), сохраняя при этом форматирование оригинального документа.

### Заменяемые символы

| Символ | Unicode | Описание | Замена |
|--------|---------|----------|--------|
| &nbsp; | U+00A0 | Неразрывный пробел | Обычный пробел |
| &nbsp; | U+202F | Узкий неразрывный пробел | Обычный пробел |
| ​ | U+200B | Пробел нулевой ширины | Удаляется |
| ­ | U+00AD | Мягкий перенос | Удаляется |
| ' | U+2019 | Правый одинарный апостроф | Обычный апостроф ' |
| — | U+2014 | Длинное тире | Короткое тире – |

## Возможности

- ✅ Поддержка форматов .txt и .docx

## Использование

## Инструменты для работы с ИИ-текстами (`ai_tools.py`)

### 1. Детекция ИИ-текста

#### Базовый анализ
```bash
python ai_tools.py detect --file document.txt
```

#### Полный анализ (с паттернами)
```bash
python ai_tools.py detect --file document.txt --patterns
```

#### Пример вывода
```
======================================================================
АНАЛИЗ ИСКУССТВЕННОСТИ ТЕКСТА
======================================================================

🟠 ОЦЕНКА ИСКУССТВЕННОСТИ: 55.2% - НЕОПРЕДЕЛЕННО

----------------------------------------------------------------------
ДЕТАЛЬНЫЙ АНАЛИЗ:
----------------------------------------------------------------------
  Однородность предложений:      57.1% ⚠️
  Характерные фразы ИИ:          100.0% ⚠️
  Частота переходных слов:        52.6% ⚠️
  Лексическая монотонность:        0.0% ✓
  Повторяющиеся паттерны:         30.0% ✓
```

### 2. Анализ паттернов

```bash
python ai_tools.py patterns --file document.txt
```

Показывает:
- Повторяющиеся фразы (n-граммы)
- Шаблонные выражения ("важно отметить", "кроме того", и т.д.)
- Чрезмерно используемую лексику
- Структурные паттерны предложений

### 3. Водяные знаки

#### Добавление водяного знака (концентрированный)
```bash
python ai_tools.py watermark-add --file document.txt --author "Иван Иванов" --output marked.txt
```

#### С метаданными
```bash
python ai_tools.py watermark-add --file doc.txt --author "Автор" \
    --metadata project=MyProject version=1.0 --output marked.txt
```

#### Распределенный водяной знак (более устойчивый к редактированию)
```bash
python ai_tools.py watermark-add --file doc.txt --author "Автор" \
    --distributed --density 0.2 --output marked.txt
```

Параметр `density` (0.0-1.0) контролирует частоту встраивания знака.

#### Проверка водяного знака
```bash
# Концентрированный
python ai_tools.py watermark-check --file marked.txt

# Распределенный (нужно указать автора)
python ai_tools.py watermark-check --file marked.txt --author "Автор"
```

#### Удаление водяного знака
```bash
python ai_tools.py watermark-remove --file marked.txt --output clean.txt
```

## Очистка текста (`text_cleaner.py`)

### Базовое использование

#### Для .txt файлов:

```bash
python text_cleaner.py input.txt -o output.txt
```

#### Для .docx файлов:

```bash
python text_cleaner.py document.docx -o cleaned_document.docx
```

### Замена исходного файла

Используйте флаг `--inplace` для замены исходного файла:

```bash
python text_cleaner.py document.txt --inplace
```

### Анализ частоты слов

Добавьте флаг `--analyze-words` для анализа топ-200 наиболее используемых слов:

```bash
python text_cleaner.py input.txt -o output.txt --analyze-words
```

### Комбинированный режим

```bash
python text_cleaner.py document.docx --inplace --analyze-words
```

- python-docx (для работы с .docx файлами)

- **Сохранение форматирования**: При обработке .docx файлов скрипт сохраняет все форматирование (шрифты, размеры, стили, таблицы)

## Технические детали

### Детектор ИИ

Использует следующие эвристики:
- **Вариативность длины предложений**: ИИ создает более однородные предложения
- **Характерные фразы**: "важно отметить", "тем не менее", "кроме того" и т.д.
- **Переходные слова**: ИИ чаще использует linking words
- **Лексическое разнообразие**: Type-Token Ratio
- **Perplexity estimation**: Приблизительная оценка на основе частоты слов

### Водяные знаки

#### Концентрированный тип:
- Встраивает метаданные в начало текста
- Использует zero-width Unicode символы (U+200B, U+200C, U+200D, U+FEFF)
- Кодирование: JSON → Base64 → Binary → Invisible chars
- Включает контрольную сумму MD5

#### Распределенный тип:
- Распределяет подпись по всему тексту
- Более устойчив к редактированию
- Вставляется после знаков препинания
- Использует хеш автора для генерации паттерна

### Анализ паттернов

- **N-граммы**: Поиск повторяющихся фраз (2-5 слов)
- **Формульные выражения**: Вводные конструкции, переходы, усиления
- **Структурный анализ**: Однородность длины предложений
- **Кластеры лексики**: Чрезмерно используемые слова

## Часто задаваемые вопросы (FAQ)

**В: Насколько точен детектор ИИ?**
О: Детектор использует эвристические методы и дает оценочную информацию. Точность зависит от качества и длины текста. Для коротких текстов (<200 слов) точность снижается. Лучше всего работает на текстах 500+ слов.

**В: Можно ли полностью скрыть водяной знак?**
О: Водяной знак использует невидимые Unicode символы, которые не отображаются в обычных редакторах. Однако при копировании в некоторые системы они могут быть удалены. Распределенный тип более устойчив.

**В: Работает ли это с кириллицей?**
О: Да, все модули полностью поддерживают кириллицу и другие Unicode-символы.

**В: Можно ли использовать без интернета?**
О: Да! Все инструменты работают полностью локально без подключения к интернету.
