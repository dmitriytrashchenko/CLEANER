# Скрипт очистки текста от ИИ-символов

Python-скрипт для удаления невидимых символов Unicode, которые часто добавляются при генерации текста с помощью ИИ.

## Описание

Этот скрипт автоматически находит и заменяет специальные символы Unicode в текстовых документах (.txt и .docx), сохраняя при этом форматирование оригинального документа.

### Заменяемые символы

| Символ | Unicode | Описание | Замена |
|--------|---------|----------|--------|
| &nbsp; | U+00A0 | Неразрывный пробел | Обычный пробел |
| &nbsp; | U+202F | Узкий неразрывный пробел | Обычный пробел |
| ​ | U+200B | Пробел нулевой ширины | Удаляется |
| ­ | U+00AD | Мягкий перенос | Удаляется |
| ' | U+2019 | Правый одинарный апостроф | Обычный апостроф ' |
| — | U+2014 | Длинное тире | Короткое тире – |

## Возможности

- ✅ Поддержка форматов .txt и .docx
- ✅ Сохранение форматирования документа (для .docx)
- ✅ Подробная статистика замен
- ✅ Анализ частоты слов (топ-200)
- ✅ Возможность замены исходного файла
- ✅ Обработка таблиц в документах Word

## Использование

### Базовое использование

#### Для .txt файлов:

```bash
python text_cleaner.py input.txt -o output.txt
```

#### Для .docx файлов:

```bash
python text_cleaner.py document.docx -o cleaned_document.docx
```

### Замена исходного файла

Используйте флаг `--inplace` для замены исходного файла:

```bash
python text_cleaner.py document.txt --inplace
```

### Анализ частоты слов

Добавьте флаг `--analyze-words` для анализа топ-200 наиболее используемых слов:

```bash
python text_cleaner.py input.txt -o output.txt --analyze-words
```

### Комбинированный режим

```bash
python text_cleaner.py document.docx --inplace --analyze-words
```

## Технические детали

### Требования

- Python 3.6+
- python-docx (для работы с .docx файлами)

### Особенности реализации

- **Сохранение форматирования**: При обработке .docx файлов скрипт сохраняет все форматирование (шрифты, размеры, стили, таблицы)
- **UTF-8 кодировка**: Все текстовые файлы обрабатываются в кодировке UTF-8
- **Обработка таблиц**: Скрипт корректно обрабатывает текст внутри таблиц в документах Word
- **Статистика**: Подсчитывается количество замененных символов каждого типа

## Примеры использования

### Пример 1: Очистка одного файла

```bash
python text_cleaner.py ai_generated_text.txt -o clean_text.txt
```

### Пример 2: Пакетная обработка с заменой

```bash
for file in *.txt; do
    python text_cleaner.py "$file" --inplace
done
```

### Пример 3: Очистка с анализом

```bash
python text_cleaner.py report.docx -o report_clean.docx --analyze-words
```

## Устранение неполадок

### Ошибка: "библиотека python-docx не установлена"

**Решение:**
```bash
pip install python-docx
```

### Ошибка: "Файл не найден"

**Решение:** Убедитесь, что путь к файлу указан правильно. Используйте абсолютные пути, если возникают проблемы.

### Ошибка кодировки при обработке .txt файлов

**Решение:** Убедитесь, что ваш файл сохранен в кодировке UTF-8.
